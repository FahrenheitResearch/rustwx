# California Fire Weather Pilot API Integration Guide

This guide is written for a developer or coding agent integrating the hosted
California Fire Weather pilot API into a website such as cafire.org.

Base URL:

```text
https://cafire.wxsection.com
```

The API is currently a public, read-only pilot for HRRR California products.
Treat every product as experimental model guidance, not an official forecast,
warning, evacuation product, or safety-of-life decision product.

## Integration Rules

- Use the JSON manifests as the source of truth for static plots.
- Do not hardcode R2 object paths.
- Use `.webp` artifact URLs for lightweight galleries, scrub bars, and
  animations. Keep `.png` URLs as the full-quality fallback.
- Ignore render report JSON files in static plot galleries.
- Load the hourly, diurnal, lightning, and satellite manifests separately.
- For map clicks, call the meteogram endpoint with the clicked latitude and
  longitude.
- Expect the product list to grow.

## Endpoints

### Health

```http
GET /health
```

Use this for a basic uptime/status check. It returns service status, the rustwx
version, cache paths, R2 status, and meteogram warm-cache state.

### Product Catalog

```http
GET /api/v1/public/products
```

Returns the currently exposed HRRR product catalog:

- `default_products`: products generated by the hosted California pipeline.
- `direct`: rustwx direct-field product slugs.
- `light_derived`: fast derived product slugs.
- `heavy_derived`: heavier ECAPE/severe product slugs.
- `windowed`: accumulation, max, min, and range product slugs.

Use this for labels, picker options, and debugging. Do not assume every catalog
product is generated in the California static plot pipeline.

### Latest Hourly Static Plots

```http
GET /api/v1/public/latest-artifacts
```

Returns the latest hourly HRRR California static plot manifest. Important
fields:

```text
date_yyyymmdd
cycle_utc
domain
products
available_forecast_hours
hours[].forecast_hour
hours[].uploaded[].key
hours[].uploaded[].url
hours[].uploaded[].format
hours[].uploaded[].size_bytes
```

Each static plot is published as a full-quality PNG and a lightweight WebP with
the same basename. Build interactive galleries and time scrubbers from `.webp`
URLs when present, and link the matching `.png` for full-resolution inspection.

Current hourly products include near-surface temperature, RH, dewpoint, wind
gusts, VPD, fire weather composite, 1-hour QPF, 1-hour max 10 m wind,
visibility, and smoke products.

### Latest Diurnal Static Plots

```http
GET /api/v1/public/latest-diurnal-artifacts
```

Returns the latest extended-cycle manifest for fixed diurnal temperature range
products:

```text
2m_temp_0_24h_range
2m_temp_24_48h_range
2m_temp_0_48h_range
```

This endpoint is intentionally separate from `latest-artifacts`. The newest
hourly HRRR cycle may only have f000-f018 available, while diurnal ranges need
f024 and f048 from an extended 00Z/06Z/12Z/18Z cycle.

### Latest GLM Lightning Plot

```http
GET /api/v1/public/latest-lightning-artifacts
```

Returns the latest GOES-West GLM lightning manifest for California. The artifact
set includes PNG, WebP, and JSON flash data. Use the WebP URL for browser
preview and the PNG URL for full-quality inspection. The manifest can report
`flash_count_in_domain: 0`; that means the recent GOES-West files had flashes
elsewhere but none inside the California domain.

The hosted worker polls NOAA every 30 seconds and skips republishing when no
new GLM object is available. In normal operation, expect the published lightning
map to trail latest NOAA GLM availability by roughly 1-2 minutes.

### Latest GOES Satellite Plots

```http
GET /api/v1/public/latest-satellite-artifacts
```

Returns the latest GOES-West ABI/GLM satellite manifest for the Pacific
Southwest. Products are rendered from raw NOAA NetCDF and published as PNG plus
WebP. Important fields:

```text
satellite
abi_product
scan_id
scan_time_utc
domain
bounds
products
product_catalog[].name
source_keys
glm_source_keys
artifacts[].product
artifacts[].display_name
artifacts[].mapbox_overlay
loops[].url
hours[].uploaded[].url
```

Use `artifacts[].mapbox_overlay.coordinates` and `image_url` for a Mapbox image
source when you want a georeferenced overlay. Use `product_catalog` for
website-facing names such as `GeoColor`, `GLM FED3+GeoColor`, and `Band 13`.
The worker defaults to 5-minute polling and skips unchanged ABI scans.

### Latest GLM Lightning GeoJSON

```http
GET /api/v1/public/latest-lightning.geojson
```

Returns a GeoJSON `FeatureCollection` of the current California-domain GLM
flashes. This is the easiest Mapbox input. Each point feature uses
`[longitude, latitude]` coordinates and includes `time_utc`, `energy_j`,
`area_m2`, and `source_file` properties. The response also includes manifest
metadata such as `time_window`, `latest_glm_key`, `flash_count_total`, and
`flash_count_in_domain`.

Mapbox source pattern:

```js
map.addSource("cafire-lightning", {
  type: "geojson",
  data: "https://cafire.wxsection.com/api/v1/public/latest-lightning.geojson"
});

map.addLayer({
  id: "cafire-lightning",
  type: "circle",
  source: "cafire-lightning",
  paint: {
    "circle-radius": 4,
    "circle-color": "#facc15",
    "circle-stroke-color": "#7c2d12",
    "circle-stroke-width": 1
  }
});
```

### Public Meteogram PNG

```http
POST /api/v1/public/meteogram.png
Content-Type: application/json
```

Example request:

```json
{
  "lat": 40.5865,
  "lon": -122.3917,
  "forecast_hour_start": 0,
  "forecast_hour_end": 48,
  "label": "Redding"
}
```

Example response shape:

```json
{
  "artifact": "hrrr_point_meteogram_png",
  "url": "https://...",
  "date_yyyymmdd": "20260427",
  "cycle_utc": 12,
  "forecast_hours": [0, 1, 2]
}
```

The response URL points to a rendered six-panel HRRR meteogram PNG. Repeat
requests for the same run, point, label, and hour range can return a cached PNG.

The service is California-only for this pilot. Points outside the California
pilot bounds return HTTP 400.

### Public Meteogram JSON

```http
POST /api/v1/public/meteogram
Content-Type: application/json
```

Use the same body as `meteogram.png`. This returns sampled numeric time-series
data instead of a rendered PNG. Use this for custom website charts, tooltips, or
derived UI summaries.

## Static Plot Gallery Pattern

1. Fetch `/api/v1/public/latest-artifacts`.
2. Fetch `/api/v1/public/latest-diurnal-artifacts`.
3. Fetch `/api/v1/public/latest-lightning-artifacts`.
4. Flatten each manifest:

```text
for hour in manifest.hours:
  for upload in hour.uploaded:
    if upload.url ends with ".png" or ".webp":
      create gallery record:
        product = parse from key or display from manifest/products
        forecast_hour = hour.forecast_hour
        png_url = upload.url if suffix is ".png"
        webp_url = upload.url if suffix is ".webp"
```

5. Show hourly, diurnal, and lightning plots as separate tabs or sections.
6. Use `date_yyyymmdd`, `cycle_utc`, and `forecast_hour` visibly near HRRR
   plots; use `time_window` for GLM lightning plots.
7. For a scrub bar, preload/display `webp_url || png_url`; open `png_url` for
   detail views.

## Mapbox Click Pattern

On map click:

```js
const response = await fetch("https://cafire.wxsection.com/api/v1/public/meteogram.png", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    lat: event.lngLat.lat,
    lon: event.lngLat.lng,
    forecast_hour_start: 0,
    forecast_hour_end: 48,
    label: "Selected point"
  })
});

const meteogram = await response.json();
```

Display `meteogram.url` as an image. If the request returns 400, show a clear
message that the point is outside the California pilot domain.

## Current Operational Notes

- The static plot backend pulls from NOMADS for low-latency HRRR availability.
- Static plots are uploaded to R2 and served through public artifact URLs.
- Static plots include PNG and lower-bandwidth WebP variants.
- A dedicated GLM lightning worker publishes a recent GOES-West California
  overlay as PNG/WebP, JSON flash data, and GeoJSON points for Mapbox.
- The meteogram path uses a warmed California HRRR point store for fast point
  sampling.
- The service logs public meteogram request performance server-side, including
  sample/render timing and cache path, without logging user-provided labels.
- Operators have a protected rolling metrics endpoint and local SSH-backed
  dashboard for API and meteogram traffic. Direct static plot image downloads
  are served from R2 and should be measured with Cloudflare/R2 analytics.
- The hosted service prunes its transient local HRRR cache in the background;
  public artifact URLs remain R2-backed and manifest-driven.
- The API currently returns PNG products, not Mapbox raster tiles.
- A future tile/overlay API should use the same manifest-driven pattern.

## Required Disclaimer

Any public display should include language equivalent to:

```text
Experimental model visualization. Not an official forecast, warning, evacuation,
or safety-of-life product. For official warnings and evacuation information,
use NWS, CalFire, and local emergency management sources.
```
